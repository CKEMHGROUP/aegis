User Manual

Version 0.13.3 · macOS · Made by AEGIS QUANTUM SYSTEMS © 2026

A privacy gateway for AI chats — personal data is found on your Mac, replaced with placeholders, reviewed by you, and restored in the answer. Nothing leaves this Mac until you approve it.

1 · What AiLOCK does

When you send a message, AiLOCK works like a lock between you and the AI provider:

  • Detect — names, emails, phone numbers, addresses, IDs, card numbers and more are found locally (Microsoft Presidio + spaCy models — no cloud call).
  • Sanitise — every personal value is replaced by a placeholder such as <PERSON_1> or <EMAIL_ADDRESS_1>.
  • Review — you see exactly the text that would leave your Mac and approve or cancel it.
  • Send — only the sanitised text goes to the provider you chose.
  • Restore — the answer comes back with the real values put back. Only you see the real data.

A lock switch in the header toggles this protection on and off. With the lock open, messages pass through like a normal AI chat.

2 · First launch — guided setup

The first time you open AiLOCK, a short setup walks you through the essentials. Reopen it any time via AiLOCK → Guided Setup…

Step 1 — AI provider. Choose Google Gemini, OpenAI, Anthropic Claude or a Custom/Local endpoint and paste your API key. Keys live in the macOS Keychain, never in a file.

Step 2 — Email (optional). Add IMAP accounts to attach inbox digests to requests. Mail is read-only — nothing is marked as read or changed.

Step 3 — Document language. Automatic detection covers Portuguese, Spanish, German and English — fix a language only if your documents always use it.

3 · The main window

The header, left to right:

  • Ask / Folders — chat with your AI, or sanitise a whole folder.
  • Provider selector — the centred Google Gemini ▾ menu chooses where requests go.
  • Lock switch — the lock image toggles sanitising ON (closed) or OFF (open).
  • Ready / Setup needed — whether the selected provider is configured.
  • New Chat — saves the current conversation to History and starts fresh.
  • Inspector — the detailed detection view.
  • ⋯ — Settings, terms, data handling, diagnostics, logs.

The composer accepts typing, pasted text, dropped files and inbox digests. Return sends; Shift+Return adds a line.

4 · Your first request

Step 1 — Review before sending

Type a message and press Send. If personal data is found, the review card shows what will be hidden, where it goes, and lets you untick items that shouldn't be redacted.

Step 2 — The answer

After you approve, the answer arrives with real values restored. The What the AI said (tagged) tab shows the raw provider text with placeholders highlighted — verify nothing personal crossed the wire.

5 · Continuing the conversation

AiLOCK chats continuously like a normal AI app — follow-ups carry the sanitised transcript, and placeholders stay stable: <PERSON_1> is the same person throughout. Every turn still goes through review.

Editing a sent request: every request bubble has an Edit ↺ link. Clicking it rewinds the thread to that request, restores the text into the composer, and drops everything after it — change the request and send again. Ctrl+R amends the most recent request.

6 · Sanitise ON / OFF

Click the lock next to the provider name:

  • Closed lock (ON) — detection, review, sanitised send, local restore. The default.
  • Open lock (OFF) — messages pass through exactly as typed, like a normal chat.
Context never crosses the boundary: a raw turn is never mixed into a later sanitised send, and sanitised context is never used in raw mode. Switching the lock starts a fresh context.

7 · New Chat and History

New Chat (Ctrl+N) doesn't delete anything — the conversation is saved to Chat History (Ctrl+H) and the window clears. Opening a saved chat restores it completely — messages, answers and placeholders — so you can continue where you left off.

History is stored only on this Mac, obfuscated and readable only by your user account.

8 · Attaching content

Documents — drop files onto the window or use + / Ctrl+O. Text, PDF (scanned pages via Apple Vision OCR) and Word files are read locally; the file name is never sent — only its sanitised text, labelled generically (Document 1).

Inbox digest — the ✉ button / Ctrl+Shift+M fetches the period you choose over IMAP and attaches a digest. Mail is opened read-only.

9 · Folders — batch sanitising

Switch to Folders, pick a folder, and AiLOCK scans for new or changed files. Press Sanitise to produce a shareable copy in ~/Documents/AiLOCK Sanitised — every file renamed Document-001.txt…, no original names or mapping inside the shared folder.

  • The same value gets the same placeholder across all files of a batch.
  • Items the detector is unsure about are hidden rather than left in.
  • Keep an encrypted key stores an AES-GCM-encrypted mapping locally (key in the Keychain) so a returned file can be restored via Restore a returned file…

10 · The Inspector

The Inspector (Ctrl+I) is the detailed back end of the current request:

  • Detections — tick/untick redactions, add manual terms, Always redact this value.
  • Sent text — the literal payload that leaves the Mac, tags highlighted.
  • Mapping — placeholder → real value; Reveal values toggles visibility.
  • Run log — timings, counts, error classes. Never document text.

13 · Privacy notes

  • Stays on this Mac: originals, the placeholder mapping (memory only), terms, API keys (Keychain), diagnostic logs, chat history.
  • Leaves this Mac: only the sanitised text you approve — unless the lock is open, in which case text passes through like a normal chat.
  • Detection is not perfect — always read the review step. Pseudonymised text can still identify people through context; under GDPR it remains personal data.
  • The inactivity timer (Settings → Privacy) wipes the visible conversation without archiving.

14 · Troubleshooting

SymptomWhat to do
“Setup needed” pillAdd the API key in Settings → AI Providers, or rerun Guided Setup.
Composer disabled at launchThe detection engine is still loading — a few seconds, or switch the lock OFF to send raw meanwhile.
Detection engine failedThe app continues with sanitising OFF. Restart; check the run log in the Inspector.
Keychain prompts (unsigned build)Expected — macOS guards the Keychain for unsigned apps. AiLOCK falls back to a protected per-user file if denied.
A name wasn't detectedAdd it under Settings → Privacy → always-redacted terms, or tick it in the Inspector for that request.
Email won't connectUse an app password, not your login password. ProtonMail needs the local Bridge.
